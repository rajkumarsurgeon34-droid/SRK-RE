argument-hint: <path-to-app> "<feature>"

Target and feature: $ARGUMENTS

Use the `srk-reverse-engineering` skill. Goal: learn the idea, then build an
original version.
1. Locate the feature's code from UI strings, resource names or API paths.
2. Explain the mechanism step by step in plain language, each step with
   evidence (file, class/function, string).
3. Note the libraries, algorithms and data formats it relies on.
4. Design an original implementation for the user's own project (current
   working directory if it has code): components, data flow, and suggested
   libraries. Reimplement the behaviour; do not copy proprietary code, assets
   or text.
5. Ask whether to start building it.
